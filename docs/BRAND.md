# Seed Street

The product is now Seed Street. The compact green mark depicts two opposing street signs on one post, with an S-like silhouette. It is a nod to Wall Street signage and keeps the existing black, white and #00c805 palette.

- Shared app wordmark: `src/components/seed-street-brand.tsx`
- Standalone transparent mark: `public/seed-street-mark.svg`
- Transparent white wordmark: `public/seed-street-logo.svg`
- Browser icon: `src/app/icon.svg`

The live and demo navigation, page metadata, help titles and agent display labels use Seed Street. Existing browser storage keys, report paths, trace identities, frozen benchmark prompts and historical evidence retain their original identifiers so the rename preserves saved work and experiment reproducibility.
